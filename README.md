# Linux-commands-OverTheWire
### Ishaan Jog

This repository contains the documentations and notes that were taken when solving the **Bandits** game in OverTheWire.  
https://overthewire.org/wargames/bandit/  

**Contents:** Documentations for passing level 0, going from level 0 to level 1, from level 1 to level 2, and so on.  
Each level requires executing certain Linux commands in order to obtain the password for the next level.
